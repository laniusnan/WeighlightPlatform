## 旁白全文

> 欢迎来到 AI 模型轻量化平台。它统一管理模型、压缩与微调：六种结构化剪枝、量化感知训练、LSQ 全量 INT8、知识蒸馏、以及 Excel 指令集驱动的 LoRA 微调，全部开箱即用。只需上传模型、选择方法，平台就会在后台执行并把可部署产物交付给你。实验页的十余张自检卡，一键验证每一条技术链路，从入门到生产都有据可查。CPU-only 服务器已稳定运行；真实的 Qwen LoRA 微调也在本地 GPU 上完成验证。这就是我们正在构建的，从模型到部署的完整闭环。

## 演示素材说明（本次计划）
- Qwen 段：用 `llm_quantize`（weight-only RTN INT4，group=128, sym）演示，**无需校准数据集**，
  展示 OpenVINO IR + 量化前后 CPU 延迟对比。
- CIFAR-100 段（剪枝/QAT）：把子集转成“按类别分文件夹 jpg + zip/tar”，配 PyTorch CNN 教师；
  校准数据仅用于视觉静态 INT8（可选图片集）。
- LoRA 微调段（如需保留）：HF Qwen + 指令 Excel（问题=>回答），仅在本地 GPU 上跑。
